# 020 — Rich Text Editor

> Status: SHIPPED · Area: Editor · Last verified: 2026-07-19

## What

- A TipTap-based rich text editor where the user writes a LinkedIn post and applies formatting via a toolbar: bold, italic, strikethrough, underline, four Unicode font styles (double-struck, script, monospace, fraktur), an emoji picker, bullet list, ordered list, plus undo and redo. The formatting is converted to LinkedIn-compatible Unicode glyphs (for example mathematical bold/italic code points) so the styling survives a paste into LinkedIn, which strips real markup.

## Why

- LinkedIn's composer has no native text styling. Authors who want bold or italic emphasis must paste pre-styled Unicode. This editor gives a familiar WYSIWYG surface and produces the exact Unicode LinkedIn renders, so emphasis is preserved when copied across.

- Mark mapping from TipTap mark types to transform keys, including the `fontStyle` attribute lookup: `components/tool/utils.ts:232-257`.

## Open questions / known gaps

- TipTap `StarterKit` also enables headings, blockquote, code block and horizontal rule by default, but no toolbar buttons expose them; they are only reachable via input rules or keyboard shortcuts.
- The `fontStyle` mark does not substitute glyphs inside the editor: the editor shows a highlight and an approximate font-family hint, and the real Unicode letters appear in the preview and in the copied text.
- Double-struck and fraktur have gaps in their Unicode blocks; the capitals encoded earlier in Letterlike Symbols are substituted by hand (`components/tool/utils.ts:35-51`), so any other unassigned code point in those ranges would render as tofu.
